# Modulo 09: Redes Neurais e CNNs Basicas

Introducao pratica a Redes Neurais Convolucionais com Keras/TensorFlow.

## Conteudo dos Scripts
- `15_cnn_mnist.py`: Construcao, treinamento e avaliacao de CNN classica para digitos MNIST.
- `16_visualizar_kernels.py`: Visualizacao dos pesos aprendidos pelos filtros da primeira camada.
- `17_visualizar_feature_maps.py`: Extracao e plotagem dos mapas de ativacao intermediarios.
- `18_cnn_cifar10.py`: Classificacao de imagens coloridas com o dataset CIFAR-10.
- `19_transfer_learning_mobilenet.py`: Transfer Learning utilizando pesos pre-treinados da MobileNet.
- `20_deteccao_objetos_conceito.py`: Conceitos de localizacao e classificacao de objetos.
