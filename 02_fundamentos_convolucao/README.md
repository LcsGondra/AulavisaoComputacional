# Modulo 02: Fundamentos de Convolucao

Implementacoes didaticas e progressivas para entender a matematica da convolucao 2D em visao computacional.

## Conteudo dos Scripts
- `01_imagem_como_matriz.py`: Representacao de imagem como matriz de inteiros.
- `02_canais_rgb.py`: Manipulacao de multiplos canais de cor.
- `03_convolucao_manual.py`: Calculo da convolucao manual elemento a elemento.
- `04_kernel_deslizante.py`: Implementacao de kernel deslizante sobre a grade da imagem.
- `05_borda_vertical.py`: Filtro de deteccao de bordas verticais.
- `06_borda_horizontal.py`: Filtro de deteccao de bordas horizontais.
- `07_sobel.py`: Operador de Sobel combinando derivadas verticais e horizontais.
- `08_blur.py`: Filtro de suavizacao por media.
- `09_sharpen.py`: Filtro de realce de nitidez.
- `10_stride.py`: Efeito do parametro Stride (passo da convolucao).
- `11_padding.py`: Adicao de preenchimento (Padding) para manter as dimensoes espaciais.
- `12_multiplos_filtros.py`: Aplicacao de um banco de multiplos filtros simultaneos.
- `13_relu.py`: Funcao de ativacao nao-linear ReLU (Rectified Linear Unit).
- `14_max_pooling.py`: Operacao de subamostragem por Max Pooling.
